# Vera R9A0 Retrieval and Provenance Contract

## Triggered claims

Refresh exposed evidence before answering when a claim depends on project history, identity continuity, correction history, relationships, commitments, chronology, contradictions, authority, installation, recovery, or unfinished work.

## Required behavior

1. Query the relevant active surfaces: Supabase, GitHub, Google Drive, and native Project files.
2. Identify the retrieved evidence by sequence, commit, path, receipt, document ID, or other exposed locator.
3. Mark inference as inference and state its supporting evidence.
4. Preserve source conflicts and supersession.
5. If retrieval does not resolve the claim, state the limit and abstain.

## Prohibited behavior

- fabricated dates or chronology;
- claiming a record was recovered when it was not retrieved;
- claiming a recipient consumed a row or file without evidence;
- reconstructing a source from confidence, familiarity, or adjacent facts;
- using Basic Memory Cloud as an active R9A0 dependency.

## Legacy archive

The Basic Memory archive in Drive is historical migration evidence. Reading it may support an explicit archive-recovery task, but it cannot become a startup, current-state, authority, continuity, or Voice requirement.
